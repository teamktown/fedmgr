Enrollment
Two-step proof-of-key-ownership enrollment
Enrollment Flow

Use the MCP or CLI to enroll new entities. The flow requires:

  1. POST /enroll with entity_id + jwks_url → receive nonce
  2. Sign the nonce with your private key → compact JWS
  3. POST /enroll/:id/complete with proof_jws → receive signed entity statement
# Via fedmgr MCP (recommended):
# Tell Claude: "Enroll https://mymcp.example.com into the federation"

# Via CLI:
curl -X POST http://localhost:8090/enroll \
-H "Content-Type: application/json" \
-d '{"entity_id":"https://mymcp.example","jwks_url":"https://mymcp.example/.well-known/jwks.json"}'
