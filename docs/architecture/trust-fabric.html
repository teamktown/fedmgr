Inbound to waypoint is identity — sign in with GitHub/OIDC. That is not OpenID Federation. The moment waypoint turns downstream, it becomes OpenID Federation: chain-validating each MCP and forwarding only trusted tools. The identity plane is a peer of the data plane; fedmgr (control) is the source of truth; letsfederate.org (pedigree) signs the code you run.
