🔍 How Federation Trust Works:

  1. Login: User authenticates with GitHub via Federation Admin
  2. Token Issuance: Federation Admin issues signed JWT with trust marks
  3. MCP Request: User presents JWT token to MCP server
  4. Validation: MCP server validates token with Federation Admin
  5. Trust Chain: Verifies trust chain from anchor to user
  6. Access Granted: MCP server provides authenticated response
